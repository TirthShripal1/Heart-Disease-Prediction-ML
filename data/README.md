# Dataset instructions

No dataset is included. Put your CSV at `data/heart.csv` (or pass another path with `--data`).

The default target column is `target`. The starter scripts expect a binary target encoded as 0 and 1. Verify the target meaning and encoding from the documentation of the exact dataset you download.
